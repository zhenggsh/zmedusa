## 1. 产品概述与定位

### 1.1 产品简介

Bothhappy（https://www.bothhappy.com）是一个面向全球市场的**游戏数字商品充值电商平台**，专注于为手游和端游玩家提供安全、快捷、便利的虚拟货币直充（Direct Top-Up）服务。平台作为连接游戏厂商与终端玩家的桥梁，通过与全球多家游戏公司建立官方合作伙伴关系，为玩家提供正规渠道的充值服务。

### 1.2 品牌定位

| 维度 | 描述 |
|------|------|
| **品牌 Slogan** | "Pay safe, fast and fun with Both·Happy" |
| **目标用户** | 全球范围内的手游/端游玩家 |
| **核心价值** | 安全、快速、有趣的游戏充值体验 |
| **业务模式** | B2C 数字商品直充平台 |
| **市场定位** | 全球游戏数字商品充值服务商 |

### 1.3 平台规模

- 已与全球 **30+ 家游戏公司和游戏工作室** 建立官方合作伙伴关系
- 服务覆盖 **数千万玩家** 的充值需求
- 提供多语言、多货币的全球本地化服务
- 支持热门手游、端游的虚拟货币直充业务

### 1.4 竞争优势

1. **官方合作**: 与游戏厂商直接合作，确保充值渠道的正规性和安全性
2. **全球覆盖**: 支持多语言和多货币，服务全球不同地区的玩家
3. **价格优势**: 提供具有竞争力的价格，并带有明确的折扣标识
4. **便捷体验**: 简化的充值流程，用户可快速完成购买
5. **多元支付**: 支持 Visa、MasterCard、PayPal、Alipay 等多种主流支付方式

## 2. 核心业务功能

### 2.1 游戏虚拟货币直充（Direct Top-Up）

这是平台最核心的业务功能。用户可以通过 Bothhappy 平台直接为支持的各类游戏充值虚拟货币，无需通过游戏内购或第三方渠道。

**业务流程**:
1. 用户浏览或搜索目标游戏
2. 进入商品详情页，选择充值面额/套餐
3. 确认订单信息（游戏账号、区服等）
4. 选择支付方式并完成付款
5. 系统自动将虚拟货币充值至用户游戏账户

**支持的充值类型**:
- 游戏币直充（如 UC、Crystal、Gem 等）
- 会员/通行证购买
- 礼包码兑换
- 限定道具/皮肤购买

### 2.2 商品展示与推荐系统

平台采用多渠道商品展示策略，帮助用户快速发现目标商品：

| 展示渠道 | 说明 |
|----------|------|
| Hero Banner 轮播 | 首页顶部大图轮播，展示主打游戏和促销活动 |
| New Arrivals | 新品推荐区域，标注 NEW 标签展示新上线游戏 |
| Top Selling | 热销排行榜，展示最受欢迎的游戏商品 |
| Popular Recommendations | 个性化/热门推荐区域 |
| 搜索发现 | 通过搜索框主动查找目标商品 |

### 2.3 多语言与多货币本地化

平台提供完善的全球化服务支持：

- **语言支持**: 英语、泰语、印尼语等（可扩展更多语言）
- **货币支持**: USD（美元）、THB（泰铢）、IDR（印尼盾）等
- **实时切换**: 用户可在页面顶部自由切换语言和货币，页面内容即时更新
- **本地化定价**: 不同货币区域的商品定价自动转换和显示

### 2.4 用户账户系统

- 用户注册与登录功能
- 个人账户信息管理
- 订单历史查询
- 充值记录追踪

## 3. 用户端功能模块详细说明

### 3.1 首页（Homepage）

首页是用户进入平台的第一个触点，设计注重信息密度与视觉引导的平衡。

#### 3.1.1 页面结构

```
+--------------------------------------------------+
|  顶部导航栏 (Logo | 搜索框 | 语言/货币切换 | 登录)  |
+--------------------------------------------------+
|  Hero Banner 大图轮播区                             |
|  [主打游戏1] [主打游戏2] [主打游戏3] ...            |
+--------------------------------------------------+
|  New Arrivals 新品推荐                              |
|  [游戏卡片] [游戏卡片] [游戏卡片] [NEW标签]         |
+--------------------------------------------------+
|  Top Selling / Popular Recommendations 热销推荐     |
|  [游戏卡片] [游戏卡片] [游戏卡片] ... [See More]   |
+--------------------------------------------------+
|  Footer 页脚                                       |
+--------------------------------------------------+
```

#### 3.1.2 Hero Banner 大图轮播

- **位置**: 首页最顶部，视觉焦点区域
- **功能**: 自动轮播展示主打游戏、促销活动、品牌宣传等内容
- **交互**: 支持手动切换和自动播放
- **目的**: 吸引用户注意力，引导至重点商品或活动页面

#### 3.1.3 New Arrivals（新品推荐）

- **标识**: 每件商品带有醒目的 **NEW** 标签
- **内容**: 展示最近新上线或新合作的游戏充值服务
- **目的**: 让用户及时了解平台的最新商品扩充
- **更新频率**: 持续更新，跟随平台商品上新节奏

#### 3.1.4 Top Selling / Popular Recommendations（热销推荐）

- **展示逻辑**: 基于销量数据或平台推荐算法排序
- **商品卡片信息**: 
  - 游戏封面图
  - 游戏名称
  - 原价（带删除线）
  - 现价
  - 折扣百分比（绿色标签）
- **交互**: 点击卡片进入商品详情页
- **"See More" 入口**: 引导用户查看完整商品列表

### 3.2 商品搜索功能

#### 3.2.1 搜索框设计

- **位置**: 顶部导航栏中央区域
- **占位文字**: "PUBG Mobile Direct Top-Up"
- **搜索范围**: 支持按游戏名称搜索
- **交互方式**: 用户输入关键词后，实时或提交后展示搜索结果

#### 3.2.2 搜索场景

| 场景 | 示例 |
|------|------|
| 精确搜索 | 输入 "PUBG MOBILE" 直达游戏页面 |
| 模糊搜索 | 输入 "PUBG" 显示相关结果 |
| 类型搜索 | 按游戏类型或品类进行筛选 |

### 3.3 商品列表页

- 展示符合筛选条件的游戏商品集合
- 支持按热度、新品等维度排序
- 分页或无限滚动加载
- 每件商品展示核心信息（封面、名称、价格、折扣）

### 3.4 商品详情页

**示例URL**: `/detail/219/Snowbreak-Containment-Zone`

#### 3.4.1 页面元素

| 元素 | 说明 |
|------|------|
| 游戏标题 | 游戏名称和Logo |
| 商品描述 | 充值内容说明 |
| 套餐选择 | 不同面额的充值选项 |
| 价格展示 | 原价（删除线）+ 现价 + 折扣标签 |
| 账号输入 | 用户游戏账号/ID 输入区 |
| 区服选择 | 游戏服务器选择（如适用） |
| 购买按钮 | 确认下单入口 |
| 商品说明 | 充值流程、注意事项、常见问题 |

#### 3.4.2 价格展示规范

- **原价**: 以删除线形式展示，作为参考价格
- **现价**: 突出显示的实际销售价格
- **折扣标签**: 绿色背景标签，显示折扣百分比（如 "-30%"）
- **货币单位**: 根据用户选择的货币显示对应符号

### 3.5 用户系统（Login/Register）

#### 3.5.1 登录功能

- 支持用户名/密码登录
- 可能支持第三方社交账号登录（需进一步确认）
- 记住登录状态/自动登录选项

#### 3.5.2 注册功能

- 新用户账号创建
- 邮箱或手机号验证
- 密码设置与安全提示

#### 3.5.3 个人中心（预期功能）

- 个人信息管理
- 订单历史查看
- 充值记录查询
